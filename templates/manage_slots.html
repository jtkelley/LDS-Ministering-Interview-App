Manage Interview Slots for {{ district.name }}

Add New Slot(s)

Use this form to quickly generate recurring interview slots.
Choose a day of the week, a start time, slot duration, and how many slots you want per day.
Slots will be created for every matching day between your chosen start and end dates.

Examples:

  • If you select Monday, set the start time to 18:00, duration to 30 minutes, and number of slots to 3:
    For each Monday in your date range, slots will be created at 18:00, 18:30, and 19:00.
  • If you select Saturday, start time 09:00, duration 20 minutes, and number of slots 5:
    For each Saturday in your range, slots will be created at 09:00, 09:20, 09:40, 10:00, and 10:20.
  • Just one day and one slot: If you select Wednesday, set the start time to 15:00, duration to 30 minutes, and number of slots to 1,
    and set both the start and end date to the same Wednesday:
    Only one slot will be created at 15:00 on that specific day.
  • Slots will not be created if they would overlap with existing slots for the same district and time.
