✅ Our Recommendation

For church apps with low volume (~400 msgs/month) and volunteer management:

  • AWS SNS - Best overall value for 1-way messaging
  • 1-Way Mode - Simplest setup, add your personal number for replies
  • Estimated cost: $1.94/month (some covered by AWS free tier)

This gives you professional automated notifications while maintaining the "neighbor helping neighbor" feel.

🔧 Provider Setup Instructions

  1. Create AWS Account: Visit aws.amazon.com and sign up
  2. Create IAM User:
    • Go to IAM → Users → Create User
    • Enable "Programmatic access"
    • Attach policy: AmazonSNSFullAccess
    • Save the Access Key ID and Secret Access Key
  3. Choose Region: Select your AWS region (e.g., us-east-1, us-west-2)
  4. A2P 10DLC Registration: (Required for US numbers)
    • Go to AWS SNS Console → Mobile → Text messaging (SMS) → Register company
    • Register as "Sole Proprietor" using your personal information
    • Create a "Low Volume" campaign (~$2 one-time + $1/month)
    • Approval typically takes 1-2 business days
  5. Configure Above: Enter your Access Key ID, Secret Access Key, and Region in the AWS SNS settings section
  6. Test: Use the "Send Test SMS" button to verify setup
💡 Tip: AWS free tier includes 100 SMS messages per month for the first 12 months, reducing your costs further during the first year.

  1. Create Account: Visit twilio.com and sign up
  2. Get Credentials:
    • From your Twilio Console, copy your Account SID
    • Copy your Auth Token (click "Show" to reveal it)
  3. Get Phone Number:
    • Go to Phone Numbers → Buy a Number
    • Choose a number with SMS capability (~$1.15/month)
  4. A2P 10DLC Registration:
    • Go to Messaging → Regulatory Compliance → Register a Business
    • Register as "Sole Proprietor" with your personal details
    • Create a "Low Volume Mixed" campaign (~$4 one-time + $2/month)
    • Approval typically takes 1 week
  5. Configure Above: Enter your Account SID, Auth Token, and Phone Number
  6. Test: Send a test message to verify
💡 Tip: Twilio offers the most extensive documentation and support resources, making it great if you need extra help during setup.

  1. Create Account: Visit signalwire.com and sign up
  2. Get Credentials:
    • From your dashboard, copy your Project ID
    • Create and copy an API Token
    • Note your Space URL (e.g., yourspace.signalwire.com)
  3. Get Phone Number:
    • Go to Phone Numbers → Buy a Number
    • Choose a number with SMS capability (~$1/month)
  4. A2P 10DLC Registration:

    • Lower costs than Twilio for ongoing campaigns
  5. Configure Above: Enter Project ID, Auth Token, Space URL, and Phone Number

💡 Tip: SignalWire offers the best cost-per-message rates for 2-way messaging and advanced features if you plan to scale up later.
⚠️ Important: A2P 10DLC Registration

All SMS providers require A2P (Application-to-Person) 10DLC registration for US phone numbers. This is a US carrier requirement, not a provider choice.

  • Who: You can register as a "Sole Proprietor" using personal information (no EIN required)
  • Cost: One-time registration ($2-4) + monthly campaign fee ($1-2/month)
  • Time: Approval takes 1-7 business days depending on provider
  • Campaign Type: Choose "Low Volume Mixed" or "Low Volume Standard" for church notifications
  • Why Required: Prevents spam and ensures message delivery to US mobile carriers
