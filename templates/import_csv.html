Tip: If you successfully scraped data from LCR, it will be in this format and you can export it to CSV and re-import it here. You can create your own or edit the one you downloaded if there are mistakes or changes that need to be handled.

  • All columns are string values except companionship_id which needs to be a unique integer per companionship.
  • Everyone in the same companionship should have the same companionship_id.
  • Interviewer should always be the same for a district. i.e. District 1 is always Jane Smith. Never have different interviewers for the same district.
