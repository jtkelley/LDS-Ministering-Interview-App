SMS Options for the Church App: An Admin Guide

This guide compares three major SMS services (AWS, SignalWire, and Twilio) across two main setup options: 1-Way (manual replies) and 2-Way Automated Replies.

Key Insight:
Because we are a non-profit volunteer group without an EIN and want minimal cost/hassle, the simplest and most compliant option is to use AWS for 1-Way sending, and put a personal phone number in the message for replies.

Option 1: 1-Way Messaging (Manual Replies via a Personal Number in the Message)

This method uses the service only to send outbound messages. Replies come to a personal cell phone.

  1. Choose a Provider & Create Account: Sign up for an account (AWS is the cheapest starting point).
  2. A2P Registration (US Only): This is mandatory for all providers. Register your "Brand" as a "Sole Proprietor" using personal details. Register a "Low Volume" campaign to ensure messages deliver. This involves small one-time and recurring monthly fees.
  3. Use the API to Send: Use the respective Python libraries (boto3, signalwire, twilio) to send messages.
  4. Message Format: Ensure every message includes the church admin's personal number for replies:
    Example: Hi, your apt link is [link]. Call/text John at (555) 123-4567 for questions.

Option 2: 2-Way Automated Messaging (Replies Handled by the App)

This method automates reply handling (e.g., auto-confirmations, "STOP" handling) and keeps all communication within the app's system. It requires significant setup and a publicly accessible Python server.

  1. Lease a Dedicated Number: Lease a dedicated 10-digit number or toll-free number from the provider (monthly fee applies).
  2. A2P Registration: Complete the mandatory A2P Sole Proprietor Brand and Campaign registration.
  3. Configure Inbound Routing:
    • AWS: Configure the dedicated number to publish incoming messages to an SNS Topic, which triggers an AWS Lambda function running your Python code.
    • SignalWire/Twilio: Set up a public-facing URL in your Python Flask/Django app that the provider can send webhooks to when a message arrives.
  4. Code the Logic: Write the Python code to parse replies (STOP, YES, etc.) and send appropriate automated responses back via the API.
  5. Alert Admins: Configure the Python code to send an email or SMS notification to an admin when a message arrives that requires human interaction.

Admin Recommendation Summary

  • Use the free tier of AWS SNS for sending the booking links.
  • Add a line of text in the message providing a personal number for any questions or replies.
  • Avoid the complexity and recurring monthly fees of the full 2-way messaging systems.

Frequently Asked Questions

What are the exact Sole Proprietor registration steps on SignalWire and Twilio?

SignalWire:
  1. Sign up for a SignalWire account.
  2. Go to Messaging → Campaign Registry.
  3. Register your Brand as a "Sole Proprietor" (requires personal info, last 4 of SSN, and mobile verification).
  4. Register a "Low Volume" campaign (for non-profits, churches, etc.).
  5. Wait for approval and assign your campaign to your purchased number.
Twilio:
  1. Sign up for a Twilio account.
  2. Go to Messaging → Regulatory Compliance → A2P 10DLC.
  3. Register your Brand as a "Sole Proprietor" (requires personal info, last 4 of SSN, and mobile verification).
  4. Register a "Low Volume" campaign.
  5. Assign the campaign to your Twilio number.

Explain the types of SMS campaigns available and which one is best for a church app

  • Low Volume (Sole Proprietor): For individuals, small groups, or non-profits sending fewer than 3,000 messages/day. Best for church apps!
  • Standard Campaign: For businesses with higher volume or more complex messaging needs.
  • Charity/Non-Profit Campaign: For registered 501(c)(3) organizations (requires EIN).

For a church app: Use the Low Volume/Sole Proprietor campaign unless you have an EIN and high volume.

Explain the advantages of using dedicated SMS numbers over personal ones for a church app

  • Compliance: Dedicated numbers are required for A2P 10DLC registration and legal compliance.
  • Professionalism: Messages come from a consistent, recognizable number.
  • Privacy: Keeps personal numbers private.
  • Automation: Enables 2-way messaging and automated replies if needed.
  • Scalability: Easier to manage as your needs grow.
